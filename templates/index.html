Reasoning

AUTO can now escalate a difficult prompt to Deep without running a second model call. Standard and Deep remain hard overrides.

AUTO THINKFast local routing: trivial prompts use Direct, normal analysis uses Standard, and complex multi-step prompts use Deep.
STANDARD THINKAlways requests the model's normal thinking mode for every turn.
DEEP REASONINGAlways requests the highest supported reasoning level, with compatibility fallback for models that only support on/off thinking.
No extra inference.AUTO is a lightweight local heuristic. It does not call a planner, agent, or second model before your reply begins.

Import / Export

Move the clean Studio state between copies without carrying old Matrix Studio code.

⇩
Export workspace

Creates one portable JSON bundle containing settings, chats, reasoning history, and your custom background image when present.

⇧
Import workspace or chat

Imports a MatrixStudio2.0 workspace bundle or a single chat export. Existing chats are preserved; imported chats receive new IDs.

◈
Export theme profile

Saves appearance, density, gradients, colors, and background controls without chats or runtime settings.

◇
Import theme profile

Applies only appearance settings. Your conversations, model, runtime, and chat behavior stay untouched.

Import is additive and never deletes your current conversations.

Reset / Advanced
